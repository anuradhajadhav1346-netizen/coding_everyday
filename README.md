# Basic Programming Programs

## 1. Division of Two Numbers

Divides two numbers and shows an error if the second number is zero.

## 2. Even or Odd

Checks whether the given number is even or odd.

## 3. Greatest of Three Numbers

Finds the greatest number among three given numbers.

## 4. Palindrome Number

Checks whether the given number is a palindrome or not.

## 5. Arithmetic Operations

Performs addition, subtraction, multiplication, and division on two numbers.
## 6. Multiplication Table
Create the multiplication table of given number.
